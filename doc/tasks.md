## 一、需求原文

> 能否以 https://github.com/yuezu1026/ai-customer/blob/main/README.md 里面的内容为内容，帮我做一个建议的宣传页面，保存为这个目录下的 README.md，这个不是面向技术的，主要是面向宣传和推广的，你看如何？并且在这个目录下，设计个宣传网站？

## 二、设计决策

- **README.md 定位**：面向市场宣传/推广，而非技术文档。弱化技术栈、部署细节，突出产品价值、客户收益、功能亮点、使用场景。
- **宣传网站**：纯静态站点（HTML + CSS + JS），无需构建，双击 `index.html` 即可打开，方便直接分发。
- **内容来源**：ai-customer 仓库 README（产品定位、M1~M3 功能、目标用户）+ doc/plan.md 产品规划（定位、目标用户、商业模式）。
- **产品名称**：AI智能获客助手（AI Sales Agent）。
- **目标用户**：中小 B2B 企业、跨境电商卖家、SaaS 服务商等需要持续获客的业务团队。
- **风格**：现代、简洁、商务，翡翠绿主色调（与产品 favicon 一致），响应式布局。
