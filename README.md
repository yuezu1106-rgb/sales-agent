# 拾客 Shike AI 智能获客助手

> **让 AI 替你跑完获客全流程：找到客户 → 写好消息 → 发出去 → 跟回来。**

**拾客 Shike AI 智能获客助手（Shike AI Sales Agent）** 是一款端到端的 AI 销售智能体，专为需要持续获客的业务团队打造。它把销售最耗时、最重复的工作——找线索、写开发信、逐个跟进——交给 AI 自动完成，你只需要在关键节点做确认，就能实现 **潜客挖掘 → 个性化触达 → 客户转化** 的完整闭环。

系统基于 **SaaS 多租户模式**，租户之间数据完全隔离；同时 **代码 100% 开源（含后续所有升级功能）**——云端注册即用，想自己部署也随时可以。

## ✨ 核心能力

### 🔍 潜客挖掘 —— 线索自己找上门

输入行业、地区、关键词、规模等条件，系统自动调用合规数据源挖掘潜在客户，并结合你的历史客户画像按相似度排序。**人工筛选确认后一键入库**，自动按公司名去重，告别重复录入。

### 🧬 RAG 客户画像 —— 让 AI 学会"什么样的客户最容易成交"

导入企业历史成交客户 CSV，系统自动向量化构建画像库。每个新潜客都会得到一个 **0-100 的画像分**：分数越高，越接近你的优质客户特征。把精力花在最有希望成交的客户上。

### 📇 客户管理 CRM —— 一个页面管好所有客户

客户列表、搜索筛选、状态流转（新线索 → 已触达 → 有意向 → 已转化/无效）、跟进记录时间线、CSV 导入导出，一应俱全。每个客户的沟通历史、邮件往来、AI 建议全部沉淀在一条时间线上。

### ✉️ AI 个性化邮件 —— 一客一信，告别模板群发

AI 基于客户信息 + 历史沟通记录自动生成邮件草稿，支持模板占位符（公司名/联系人/日期等自动替换），人工确认后一键发送。**每天限频发送 + 自动附退订链接**，合规可控。

### 📥 智能收件箱 —— 回复不遗漏，跟进有建议

自动抓取客户回复邮件，AI 分析邮件意图（询价、报价、异议、跟进、积极）并生成摘要与回复建议，确认后直接落库为跟进记录。

### 💬 微信沟通工作台 —— 全渠道沟通沉淀

支持挂载微信号/昵称，沉淀沟通消息记录，AI 同样提供回复建议，邮件之外的沟通也不丢失。

## 🔁 获客闭环，四步跑通

```
① 挖掘找线索        ② 画像打分筛选        ③ AI 写信触达          ④ 收件箱跟进转化
输入条件 AI 挖掘  →  画像分排序优中选优  →  个性化邮件人工确认发送  →  AI 分析回复给出建议
```

1. **注册开通**：云端 SaaS 注册租户，开箱即用；也可拉取开源代码自行部署
2. **简单配置**：填写 AI 模型 Key、发件邮箱，保存立即生效
3. **导入历史客户**（可选）：让 AI 学会你的优质客户特征
4. **开始获客**：挖掘 → 跟进 → AI 写信 → 发送 → 回复跟进，全程一个系统搞定

## 🛡️ 为什么选择我们？

- **🔒 租户数据完全隔离**：SaaS 多租户架构，每个租户的客户资料、沟通记录严格隔离、互不可见，敏感配置加密存储
- **📖 100% 开源**：代码全部开源，后续升级的功能也全部开源，透明可审计，支持二次开发
- **🏠 可自部署**：不想用云端？拉取源码一条命令自行部署，数据完全握在自己手里
- **🤖 AI 做重复劳动，人做关键决策**：所有外发内容必须人工确认，AI 提效不越权
- **⚖️ 合规内置**：每日发送限频、退订链接自动追加、退订黑名单自动拦截，营销触达更安心
- **💰 成本透明**：AI 用量按真实 token 统计，成本一目了然，单价可自行调整
- **🚀 开箱即用**：云端注册秒上手；自部署也只需一条命令，内置数据库与全部依赖
